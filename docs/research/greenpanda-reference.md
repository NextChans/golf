# 그린판다 앱 참고 구조 (D-80·D-85)

오너가 공유한 그린판다(골프 회원권 거래 앱) 캡처를 보고 **구조와 상호작용만** 글로 정리한 자료다. 이미지는 저장하지 않는다. Googolf 화면은 이 표를 보고 Googolf 문구·색·그림으로 새로 만든다.

## 1. 홈

| 그린판다 구조 | Googolf 대응 경로 |
|---|---|
| 상단 로고·알림·관심 아이콘, 구매/판매 탭 | `/market`(구매 탭), `/market?tab=sell`(판매 탭) |
| 거래 체결 롤링 티커, 검색 진입 칸 | `/market` 티커, "어떤 회원권을 찾고 계신가요?" → `/market/search` |
| 이번주 시세 카드 | `/market/report` 진입 카드 |
| 회원권 목록(즉시 구매·인기·상승·하락 탭, 5건 + 더보기) | `/market` `ItemCardList` |
| 최근 확인한 회원권 | `RecentList`(localStorage) |
| 지역별 타일 | 지역 원형 타일 → `/market/search/results?region=` |
| 프로모 배너 캐러셀 | `PromoCarousel` |
| 친구 초대 카드 | `InviteCard`(수수료 할인 문구만) |
| 회사 정보 푸터 | `CompanyFooter`(`lib/company.ts`, 값 "(준비 중)") |

## 2. 검색

| 그린판다 구조 | Googolf 대응 경로 |
|---|---|
| 맞춤 검색: 지역(복수)·가격대(복수), 하단 초기화 + "N건 보기" | `/market/search` |
| 결과 목록(캡처 1장, D-89) | `/market/search/results` |
| 상단 바: 뒤로 + 가운데 제목 + 오른쪽 정렬 아이콘 | `TopBar`의 `right` 슬롯 `SortSheet` |
| **골프장 단위 카드**: 흰 카드·얇은 테두리, 위에 로고 사각형·골프장명(굵게)·"지역 시·홀수"·오른쪽 ›, 아래에 회원권 유형 행(연회색 라운드: 유형 라벨 왼쪽, 가격 굵게 + 전주 대비 %, ›) | `CourseCard`(글자 아바타, 유형 행 `TypeRows`) |
| 하단 중앙에 떠 있는 어두운 초록 알약 "필터 아이콘 + N개 적용됨" | 하단 중앙 "필터 · N개 적용됨" → 조건 화면 |
| 변화율 색: 상승 빨강, 보합 회색, 하락 파랑(국내 관례) | `rateClass` |

## 2-1. 골프장 상세 (캡처 2장, D-89)

| 그린판다 구조 | Googolf 대응 |
|---|---|
| 상단 바: ‹ + 골프장명(왼쪽 정렬), 스크롤해도 고정 | `CourseTopBar` |
| 전체 폭 사진(우하단 장수·확대 버튼) 아래 흰 시트(위 모서리 둥글게) | `DetailHero`(그라디언트 + "사진 준비 중") + 시트 |
| 로고·골프장명·"지역·홀수" 아래 회원권 유형 행 목록(테두리 라운드 행) | `TypeRows bordered` |
| 구분 띠 → "골프장 정보": 주소(밑줄) + 복사 아이콘, 지도, 전화·홈페이지·회원수·규모·개장일 표 | `CourseInfo`(지도는 SVG 자리) |
| 하단 고정 초록 버튼 "지금 가장 핫한 매물 보러가기" | 같은 구조의 CTA → `/market/search/results?q=<골프장명>` |

## 2-2. 떠 있는 "상담 문의"

- 상세뿐 아니라 주요 화면(홈·검색 결과·상세·골프장 상세·나의 회원권·마이페이지)에 어두운 알약으로 떠 있고, 스크롤을 내리면 글자를 접어 아이콘 원형만 남기며 멈추면 다시 펼친다(오너 지시 D-89). 로그인·가입·고객센터 등에는 없다.

## 3. 상세 (캡처 12장)

| 그린판다 구조 | Googolf 대응 |
|---|---|
| 상단 사진 + 뒤로·공유·하트, 스크롤하면 흰 바 | `DetailHero`(지역 그라디언트 + "사진 준비 중"), `DetailTopBar` |
| 골프장 로고·이름 ›, 지역·홀, 회원권 유형, 회원권 종류 선택 | `DetailSummary`(첫 글자 아바타), `KindSelect` |
| 현재 시세 ⓘ·변화율, 즉시 구매가/판매가, 최근 거래가 | `PriceCard` |
| 거래 비용 3초 계산 배너 | 같은 문구 계열 배너 → 계산기 앵커 |
| 고정 탭 4개(시세/회원권 정보/이용 정보/골프장 정보) | `DetailTabs` |
| 시세 동향 문장 + 선 그래프 + 6개월/1년/3년/전체 | `PriceTrend` |
| 실거래가 및 입찰가(체결/구매 가능/판매 입찰 표) | `DealTables` |
| 회원권 특징 카드 3장, 회원권 구성(개인/법인), 입회 필수 체크리스트, 동반 이용 | `Features`, `Admission` |
| 부킹 특이사항, 그린피 표, 카트·캐디비 | `UsageInfo` |
| 주소(복사), 지도, 전화·홈페이지·회원수·규모·개장일 | `CourseInfo`(지도는 SVG 자리) |
| 거래 비용 계산기(구매/판매, +/− 버튼, 쿠폰 안내) | `CostCalculator` |
| 시세 리포트 배너, FAQ 5개 | `ReportBanner`, `DetailFaq` |
| 떠 있는 문의 버튼 + 맨 위로, 하단 구매하기/판매하기 | `FloatingActions`("상담 문의"), `BottomCta` |

## 4. 로그인·가입 (4단계 화면)

| 그린판다 구조 | Googolf 대응 경로 |
|---|---|
| 로그인(이메일·소셜) | `/market/login`(카카오만, D-81) |
| 회원 유형 선택(개인/기업) | `/market/signup` |
| 개인 가입 1단계(소셜) → 정보 입력 → 환영 | `/market/signup/personal` → `/onboarding` 2·3단계(D-82) |
| 기업 가입(사업자명·사업자등록번호) | `/market/signup/business` |

## 5. 마이페이지 메뉴

| 그린판다 구조 | Googolf 대응 경로 |
|---|---|
| 관심 회원권·쿠폰함·판매 희망가 | `/market/mypage/favorites`·`coupons`·`asks` |

## 따라 하지 않는 것

- 로고, 사진, 일러스트, 문구(카피), 수상 마크
- 회사 정보(상호·주소·사업자번호·대표 등)
- 제휴 캐릭터·외부 브랜드 이미지
- 현금 캐시백 금액(친구 초대 등), 수수료 수치
- 실제 골프장 이름·주소·전화·시세 데이터(우리 목업은 전부 가상)
- 네이버 지도(외부 지도 이미지·API 미사용, SVG 자리만)
- "딜러 문의" 같은 그린판다 고유 표현(우리는 "상담 문의")

## 아직 못 받은 캡처

- 판매 흐름(판매 희망가 등록·내 회원권 판매)
- 상세에서 구매하기·판매하기를 눌렀을 때 화면
- 필터 시트·정렬 시트의 실제 모양(정렬 시트는 추정으로 만들었음)
- 알림·관심 화면
