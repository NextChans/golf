## 1. 서비스 개요

- **운영사**: (주)프렌즈큐브. 통신판매업 신고, 청소년보호책임자 지정 사실이 사이트 하단에 표시됨 (확인, S1)
- **정의**: 관심사가 같은 사람들이 모임에 가입한 뒤 오프라인 **정모**에서 만나는 서비스. "모임"은 그룹이고 "정모"는 모임 안의 날짜·장소가 정해진 일정 (확인, S2·S3)
- **규모(자사 주장)**: 500만 다운로드. 정모 수는 App Store에 "매주 14,000개", 소개 페이지에 "매월 약 14,000개"로 표기가 서로 다름 (확인, S2·S7). 2022년 7월 기준 직원 4명, 누적 투자 2억 원 (검색 스니펫, S8)
- **타깃 사용자**: 20~30대 직장인·대학생의 동네 취미/친목 모임 (추정. 근거: 앱 문구의 "직장인 모임, 대학생 스터디", 예시 모임의 가입 조건이 1992~2005년생)
- **연령 등급**: KR App Store 15+, 일부 국가 스토어는 9+로 표기 (확인, S7)
- **비즈니스 모델**: 기본 기능은 무료이고, **모임 단위 구독**이 수익의 중심 (확인, S3·S4·S7)
  - **무료체험모임**: 처음 개설한 모임은 일정 기간 무료로 운영. 기간이 끝나면 글쓰기·채팅이 막히고 운영이 중단됨 (확인, S3)
  - **프리미엄모임권**: 월 15,500원, 연 159,000원(다른 등록 정보는 145,000원). 멤버 중 한 명이 "스폰서"로 구독하면 그 모임이 프리미엄이 됨. 적용 모임은 변경 불가 (확인, S3·S4·S7)
  - **클래스(레슨)모임권**: 월 42,000원(다른 등록 정보는 47,000원). 정원 확대, 운영진 채팅방 귓속말, 주목받는 말풍선 제공. 다만 이 혜택 문구가 어느 이용권에 속하는지 등록 정보의 배치상 모호함 (확인/일부 모호, S7)
  - **파워유저권(개인)**: 월 2,900원, 연 29,000원. 가입 모임 비공개, 프로필 사진 확대, 가입 가능 모임 수 증가 (확인, S7)
  - **투벙 아이템**: 1회 3,300원. 정확한 기능은 미확인 (확인/기능 미확인, S7)
  - **클래스 판매 중개**: 약관상 강사(판매자)와 수강생 간 레슨 결제를 플랫폼이 중개함. 정산 시점은 레슨 시작 후 약 40일 또는 종료 후 10일이고, 플랫폼 밖 직거래는 금지 (확인, S4). 결제 대행은 (주)시옷에 위탁 (확인, S5)
  - **광고**: App Store 개인정보 라벨에 "제3자 광고" 목적의 식별자 사용이 기재됨 (확인, S7)

## 3. 운영(모임장) 관점 기능

- **권한 체계** (확인, S3·S4)
  - 모임장: 운영진 임명·해제, 모임장 위임, 모임 정보 수정, 강퇴, 공지 작성 등 전체 권한
  - 운영진: 모임 정보 수정, 멤버 관리(강퇴), 공지 작성, 귓속말(제한 설정 시)
  - 멤버: 글·댓글, 정모 참여, 채팅
  - 승계: 모임장이 나가면 운영진 중 한 명, 운영진이 없으면 멤버 중 한 명이 자동으로 모임장이 됨. 멤버가 남아 있으면 모임을 삭제할 수 없음. 회사가 정지·휴면 상태 모임장의 권한을 이전할 수 있음
- **멤버 관리**: 강퇴와 재가입 차단, 강퇴 해제. 모임장은 강퇴 판단에 책임을 지며 권한 남용이 금지됨. 멤버 개인정보를 동의 없이 공유하면 모임장 책임 (확인, S4)
- **콘텐츠 관리 의무**: 모임장·운영진은 약관이나 운영원칙에 어긋나는 글을 모니터링·삭제하고, 신고를 받으면 즉시 삭제해야 함. 회사가 플랫폼 차원의 1차 모더레이션을 모임장에게 위임하는 구조 (확인, S4)
- **정모 관리**: 일정·장소·정원·비용 표기와 참석자 목록 노출 (확인, S6). 출석 체크나 노쇼 관리 기능은 미확인
- **회비/참가비 처리**: 약관상 회원 간 금전 거래는 당사자 책임이고 모임장이 관리 책임을 짐. 영리 목적 모임 개설은 금지. 앱에 회비 결제나 장부 기능이 있다는 근거는 없음 (확인 S4 / 기능 부재는 추정). 돈을 받는 활동은 "클래스" 상품으로 따로 구분해 플랫폼 결제와 정산을 거치게 함 (확인, S4)
- **운영 비용 부담**: 무료체험이 끝나면 모임장 또는 멤버(스폰서)가 월 15,500원을 내야 모임을 유지할 수 있음. 모임장 입장에서는 이 비용을 회비로 충당하는 구조가 될 가능성이 높음 (추정)

## 4. 안전·신고·개인정보 정책 관찰

- **금지 행위** (확인, S4): 사칭, 불법 금전 거래·사기, 타인 정보 수집, 무단 상업 이용, 음란·폭력물, 부적절한 만남 주선, 명예훼손, 계정 공유, 반복 개설을 통한 홍보 등. 개설할 수 없는 모임 유형도 정해 둠(사기, 불법 거래, 영리 목적, 음란, 부적절한 관계 주선)
- **제재 체계** (확인, S4): 경고, 일시정지, 영구정지로 단계적 제재. 중대 위반은 즉시 영구정지. 모임 삭제·운영 제한, 모임장 해임 가능. 이의신청 절차 있음. 제재로 이용이 막혀도 유료 구독료는 환불하지 않음
- **오프라인 사고 면책** (확인, S4): 모임 안팎의 분쟁, 사기, 형사·민사 문제에 대해 회사는 책임지지 않는다고 명시
- **불법촬영물** (확인, S3): FAQ에서 유통 시 삭제·차단 조치와 형사처벌 가능성을 안내. 약관에는 별도 조항이 없음. 필터링 기술 적용 여부는 미확인
- **개인정보** (확인, S5·S7): 휴대폰 번호와 기기 ID를 계정 식별자로 사용하고, 주소록(친구 자동 등록)도 수집. 프로필(이름, 사진, 생년월일, 지역, 성별, 관심사)은 공개·검색 가능. 위치정보는 "지역" 항목뿐이며 GPS 수집은 명시되지 않음. 14세 미만은 법정대리인 동의를 확인한다고 기재. 부정이용 기록은 1년 보관
- **시사점**: 모더레이션 상당 부분을 모임장에게 위임하고, 금전·오프라인 리스크는 약관 면책으로 처리함. 오래된 개인정보처리방침(2017년)과 주소록 수집은 Googolf가 따라 하지 않는 편이 좋음 (추정)

## 5. Googolf 적용 제안

> 범위 결정(오너): 커뮤니티는 **골프 관련 모임만** 허용합니다. 일반 관심사 카테고리는 설계하지 않습니다.

### 5.1 골프 특화 모임 유형(카테고리 대체)

소모임의 18개 관심사 카테고리 대신 **모임 유형(type) 1개 + 보조 태그**로 구성합니다.

| 모임 유형 | 설명 | 주요 속성 |
|---|---|---|
| 지역 라운딩 모임 | 정기 필드 라운딩 | 활동 지역(기존 `region` enum 재사용), 선호 골프장, 시간대(`time_pref` 재사용) |
| 스크린골프 | 스크린 정기 모임 | 지역, 브랜드는 태그로 처리(특정 상호 노출은 지양) |
| 레슨/연습 | 연습장 동반 연습, 스터디 | 유료 레슨 판매는 P2로 별도 상품화(소모임의 클래스 모델 참고) |
| 조인·동반자 모집 | 1회성으로 빈자리를 채우는 모집 | "모임" 없이 정모(라운드) 단위로 개설 가능하게 함 |
| 구력·핸디캡별 | 실력대가 비슷한 사람끼리 | 핸디캡/평균 타수 범위, 구력 |
| 회원권 보유자 모임 | 같은 골프장 회원권 보유자 | 회원권 보유 인증(기존 `membership_deals`/보유 정보와 연동) 시 배지 |

- 보조 태그(복수 선택): 성별 구성, 연령대, 평일/주말, 초보 환영, 카트/노캐디 등
- 지역은 시·도 단위 enum으로 시작하고, GPS 위치는 수집하지 않습니다(위치정보법 이슈를 피하기 위함)

### 5.2 골프 전용 제한의 적용·모더레이션

1. **구조적 강제**: 모임 생성 시 위 유형 중 하나를 필수로 선택하게 하고 자유 카테고리는 두지 않음. 정모(라운드)는 골프장 또는 스크린·연습장 장소 선택을 필수로 함
2. **개설 심사**: P0에서는 운영자가 사후 검수하고, 모임명·소개에 금칙어 필터(술자리, 번개, 소개팅, 재테크, 대리 부킹 판매 등)를 적용. 의심 모임은 비공개로 보류
3. **신고 사유에 "골프 무관 모임"을 추가**: 일정 건수가 쌓이면 자동 비노출 후 운영자 검토
4. **활동 기반 점검**: 일정 기간 골프 정모가 0건이고 친목 게시글만 있는 모임은 운영자 검토 대상 (P1)
5. **약관 반영**: "골프 외 목적의 모임 개설 금지, 위반 시 모임 삭제" 조항 추가 (소모임 약관 12조의 개설 금지 유형을 참고)

### 5.3 MVP 범위

| 우선순위 | 범위 |
|---|---|
| **P0** | 모임 개설(유형, 지역, 소개, 정원), 공개/승인제 가입과 가입 질문 최대 3개, 역할 3단계(모임장/운영진/멤버)와 모임장 위임·자동 승계, 정모(라운드) 생성(일시, 장소=`golf_courses` 선택, 정원 4의 배수 권장, 참가비는 **표시만**), 참석 신청/취소와 정원 마감, 공지 게시판(상단 고정), 멤버 강퇴와 재가입 차단, 신고(모임·회원·게시물), 사용자 차단, 알림(기존 `notification_outbox` 알림톡 재사용: 가입 승인, 정모 확정·D-1) |
| **P1** | 일반 게시판·댓글·사진첩(이미지 필터링 포함), 대기열 자동 승격, 출석·노쇼 기록, 핸디캡/평균 타수 프로필, 추천(지역×유형×실력대), 카카오톡 초대 링크, 조인 모집 전용 피드 |
| **P2** | 실시간 채팅, 참가비 앱 내 결제(PG 정산), 회비 장부, 유료 레슨 상품, 모임 프리미엄 구독, 스코어 기록 |

- **채팅을 P2로 미루는 이유**: 모니터링 부담, 불법촬영물 대응, 인프라 비용 때문. P0에서는 공지와 댓글, 외부 오픈채팅 링크 허용 여부를 결정해 대체 (Q 참조)

### 5.4 골프 특화 아이디어

- **정모 → 부킹 요청 연결**: 정모(라운드) 확정 시 모임장이 "Googolf로 부킹 요청" 버튼을 눌러 `booking_requests`를 생성(인원, 지역, 시간대 자동 입력). 정모와 부킹 요청 1:1 매핑, 부킹 확정·제안(`booking_proposals`) 상태를 정모 화면에 표시
- **조인/동반자 모집**: 확정된 티타임의 빈자리(1~3자리)를 모임 밖에도 공개 모집. 팀 단위(4인)로 정원 관리
- **실력 매칭**: 자기 신고 핸디캡이나 평균 타수 범위로 가입·참석 조건을 설정. 검증은 P2(스코어 기록 연동)
- **회원권 연계**: 회원권 보유자 모임에 배지를 부여하고, 거래 리드로 연결(단, 커뮤니티 안 회원권 직거래 글은 금지하고 공식 거래 플로우로 유도)
- **매너 지표**: 노쇼·지각 기록을 바탕으로 한 신뢰 점수 (P1, 문토의 "매너 온도"와 유사)

## 6. 결정이 필요한 질문 (제안 기본값)

1. **모임 개설 자격**: 누구나 / 본인인증 회원 / 부킹 이력 보유자 → **기본값: 본인인증(휴대폰) 완료 회원**
2. **개설 심사**: 사전 승인 / 사후 검수 → **기본값: 사후 검수 + 금칙어 자동 보류**
3. **모임 유형 목록**: 5.1의 6개 유형으로 확정할지 → **기본값: 6개로 시작하고 분기마다 재검토**
4. **가입 방식**: 공개 / 승인제 → **기본값: 모임장이 선택, 생성 시 기본값은 승인제 + 질문 최대 3개**
5. **모임 정원**: 상한 → **기본값: 무료 100명** (소모임의 상한 수치는 미확인)
6. **개인 가입 모임 수 제한** → **기본값: 10개**
7. **정모 정원 단위**: 자유 / 4의 배수 → **기본값: 필드 라운딩은 4의 배수 권장(강제는 안 함), 스크린은 자유**
8. **참가비 처리**: 표시만 / 앱 내 결제 → **기본값: P0는 표시만, 금액·포함 항목(그린피/카트/캐디) 구조화 입력**
9. **정모와 부킹 요청 연동 시점** → **기본값: P0에 "부킹 요청 생성" 버튼만 포함(데이터 연결은 정모 ID 외래키)**
10. **채팅 제공 여부** → **기본값: P0 미제공, 외부 오픈채팅 링크 1개 등록 허용**
11. **사진첩·이미지 업로드** → **기본값: P0는 모임 대표 이미지 1장만 운영자 검수, 사진첩은 P1**
12. **최소 연령** → **기본값: 만 19세 이상**
13. **수익화** → **기본값: 커뮤니티는 무료(부킹·회원권 전환이 목적), 프리미엄 구독은 P2 이후 검토**
14. **모임장 이탈 시 승계** → **기본값: 소모임 방식(운영진 → 가장 오래된 멤버 순서로 자동 승계)**
15. **강퇴 회원 재가입** → **기본값: 불가, 모임장이 해제 가능**
16. **신고 처리 SLA** → **기본값: 영업일 24시간 이내 1차 조치, 반복 신고 3건이면 자동 비노출**
17. **노쇼 제재** → **기본값: P1에서 기록만 하고, 3회 누적 시 모임장에게 표시**
18. **회원권 직거래 글** → **기본값: 금지, 공식 회원권 거래 플로우로 유도**
